# Avalancha

Juego incremental web sobre una pila de arena abeliana: del primer grano al Infinito, y después la Cristalización.
*An incremental web game about an abelian sandpile.* El nombre es **Avalancha** en todos los idiomas.

- Jugar: https://feli202.github.io/avalancha/ · https://exponent-games.itch.io
- Discord: https://discord.gg/8qEt7E6AV

```bash
npm install
npm run dev     # http://localhost:5173 (con panel de debug)
npm test
npm run build
```
